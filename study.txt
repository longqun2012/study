#tcpdump
With containerd, wireshark docker0 can not be used, you should use the way as below to start tcpdump in minikube:
Step1: download sniff from https://github.com/eldadru/ksniff
Step2:install sniff
unzip sniff.zip
make install
Step3:
minikube  cp  ksniff/static-tcpdump /home/docker/static-tcpdump
minikube ssh
sudo chmod +x static-tcpdumpsudo ./static-tcpdump -i any -s 65535 -w test.pcap
sudo scp test.pcap ejioguo@100.76.108.56:/home/ejioguo/
